# Roadmap v3 Summary

Roadmap v3는 제품 기획 문서(`docs/plan/product_alignment.md`)와 동일한 구조를 사용하여 코드·문서·UX가 충돌하지 않도록 합니다.

## 비전
- 로컬 우선 AI 비서
- 스마트 폴더 정책 기반 보안/권한/캐시 제어
- 모듈형 에이전트 + 공용 오케스트레이터

## 릴리스 사이클
| Cycle | 초점 | 핵심 산출물 | 상태 |
| --- | --- | --- | --- |
| Cycle 0 | 코어 파이프라인 안정화 | `scan → train → chat`, 정책 엔진, 캐시 초기화 | 완료 |
| Cycle 1 | 지식·검색 비서 고도화 | 정책 스코프 전환, Work Center, translation cache 개선 | 진행 중 |
| Cycle 2 | 회의 비서 고도화 | STT/요약 파이프라인, 액션/결정 추적, 캐시 재사용 | 진행 중 |
| Cycle 3 | 사진 비서 강화 | 태깅/중복/베스트샷, GPU/ONNX 파이프라인 | 진행 중 |
| Cycle 4 | 운영 & 하이브리드 | 감사·권한 관리, 오프로딩, 리소스 모니터링 | 계획 |

## 전략 과제
1. **스마트 폴더 캐시 정책 재설계**  
   - 폴더별 2GB 제한 가정을 제거하고 사용자 정의/자동 정리 전략을 도입  
   - 전역 접근 모드(폴더 미선택) 지원을 위한 용량 계산 및 UX 노출
2. **민감 폴더 제외 옵션**  
   - 전체 접근 권한 시 사용자가 제외할 경로를 지정  
   - 정책 엔진 확장 및 UI 토글 반영
3. **폴더 인스펙터 UX 명세 정비**  
   - 캐시 사용량, 정책 상태, 민감 폴더 설정을 한 화면에서 확인  
   - `docs/guides/ui_help.md`와 코드 구현을 동기화
4. **테스트·운영 체계 강화**  
   - `docs/plan/product_alignment.md`의 체크리스트에 맞춰 자동/수동 테스트를 정비  
   - 결과는 `results/` 폴더에 축적하고 KPI 스냅샷 자동화를 완료
