# UI 도움말: 대화 비서 자동 호출 흐름

InfoPilot 데스크톱 앱의 대화 비서는 회의·사진 비서를 자동으로 호출하며 필요한 추가 정보를 직접 안내합니다. 아래 내용을 참고해 편리하게 활용하세요.

## 회의·사진 요청 처리
- 대화창에서 “회의 요약해 줘”, “사진 정리해 줘”와 같이 요청하면 오케스트레이터가 자동으로 회의 비서(`meeting_summary`) 또는 사진 비서(`photo_manager`)를 호출합니다.
- 회의 요약 요청 시에는 오디오 파일 선택 다이얼로그가 열리고, 최근에 사용한 파일 목록을 버튼으로 제공해 한 번의 클릭으로 재사용할 수 있습니다.
- 회의 비서 화면에서는 STT 백엔드를 `auto / whisper / off` 로 선택할 수 있으며, 선택값이 자동 저장되어 Whisper 실행 시 별도의 환경 변수 없이도 바로 적용됩니다.
- 사진 정리 요청 시에는 폴더 선택 다이얼로그가 열리며, 여러 폴더를 입력 폼에 추가하거나 최근 목록에서 골라 한 번에 지정할 수 있습니다.

## Follow-up 메시지와 입력 폼
- 대화 비서가 더 많은 정보를 알아야 할 때는 “회의 오디오 파일 경로를 알려 주세요” 같이 follow-up 메시지를 출력합니다.
- 다이얼로그에서 직접 경로를 입력할 수도 있고, `찾아보기` 버튼으로 파일/폴더 탐색기를 열어 선택할 수도 있습니다.
- 입력을 취소하면 대화창에 취소 안내가 표시되고, 동일한 요청을 다시 보내면 언제든 이어서 진행할 수 있습니다.

## 진행 상태, 취소, 재시도
- 회의/사진 작업이 실행되면 상태 표시줄에 현재 단계(전사, 요약, 분석 등)가 실시간으로 갱신됩니다.
- 대화창 하단에 `취소` 버튼이 활성화되어 장시간 실행 중인 작업도 중간에 중단할 수 있습니다. 취소 요청은 백그라운드 파이프라인에 전달되어 가능한 가장 빠른 시점에 종료됩니다.
- 회의 요약은 자동으로 `enable_resume` 옵션이 활성화되어, 같은 오디오 파일을 다시 실행하면 중단된 지점부터 이어서 처리합니다.
- 단계별 성공/실패 기록은 내부 메타데이터(`stages`)에 남아 워크센터 로그, CLI 결과, 디버깅 시 확인할 수 있습니다.

## 폴더 인스펙터 & 캐시 정보
- Work Center의 **폴더 인스펙터** 패널은 스마트 폴더별 정책, 캐시 사용량, 민감 폴더 제외 여부를 한눈에 보여줍니다.
- “캐시 사용량”은 해당 폴더가 생성한 인덱스/요약 캐시가 실제로 차지하는 디스크 용량으로, `data/cache/<폴더 식별자>/`와 STT/요약 캐시 경로를 합산해 계산합니다.
- 캐시 정책은 `docs/plan/product_alignment.md` 지침에 맞춰 사용자 정의(최대 용량, 자동 정리 등)를 지원하도록 리팩토링 중입니다.
- 폴더를 지정하지 않고 전체 접근 권한을 허용하면 인스펙터가 전역 캐시 사용량을 표시하고, 민감 폴더 제외 토글을 통해 특정 경로를 즉시 차단할 수 있습니다.
- 민감 폴더 토글을 활성화하면 정책 파일에 제외 경로가 기록되고, 이후 스캔·요약 단계에서 해당 경로는 자동으로 건너뜁니다.
