| 문서 | 설명 |
| --- | --- |
| `architecture.md` | 파이프라인 계층 구조, 핵심 모듈, 공통 인프라 |
| `mvp_changelog.md` | MVP 이후 변경 이력과 주요 기능 추가 내역 |
| `iteration_plan_round6.md` | 6차 개선 라운드 계획(기능/테스트/RACI) |
