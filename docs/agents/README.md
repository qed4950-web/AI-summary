# 에이전트 문서

에이전트 관련 설계와 운영 가이드는 `docs/agents/` 하위에 정리합니다.

| 디렉터리 | 주요 내용 |
| --- | --- |
| `document/` | 문서 비서(검색·요약) 아키텍처, 실행 가이드 |
| `meeting/` | 회의 비서(전사·요약) 구조, 운영 절차, 비용 전략 |
| `photo/` | 사진 비서(태깅·중복 정리) 파이프라인 및 사용법 |

새 문서를 추가할 때는 하위 README에 목록을 갱신하고, 관련 파이프라인 코드(`core/agents/*`)와 버전 정보를 함께 기록해 주세요.
