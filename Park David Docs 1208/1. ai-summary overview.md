# ✅ **AI-summary 전체 문서 (파트 1/?)**

## **1. Executive Overview (제품 실행 요약)**

AI-summary는 **로컬 문서 기반 의미 검색·요약·대화 시스템**으로,
“스마트 폴더(Smart Folder)”라는 데이터 경계 컨셉 위에서 RAG, STT, 요약, 에이전트 기능이 동작하는 **완전한 오프라인 AI 도구**다.

### 🎯 **제품 핵심 가치**

1. **오프라인에서도 안전하게 작동**

   * 인터넷 없이 모든 AI 기능 제공
   * 로컬 모델(E5 / BGE / LLaMA.cpp) 사용

2. **문서 자동 관리 + 의미 검색**

   * 문서 → 스캔 → 추출 → 임베딩 → 학습 → 대화
   * 변경된 파일만 증분 처리

3. **에이전트 기반 워크플로우**

   * Meeting Agent (STT → 요약 → 액션)
   * Photo Agent
   * Knowledge Agent (RAG)

4. **스마트 폴더 기반 접근 제어**

   * 어떤 에이전트가 어떤 파일을 읽을 수 있는지 명확히 제한
   * 정책 기반 마스킹 / 거부 처리

---

## **2. System Principles (시스템 철학)**

### 2.1 Offload 가능한 것은 모두 로컬로

* remote inference 없음
* remote vector DB 없음
* LLaMA.cpp / SentenceTransformer만 사용 가능

### 2.2 명확한 경계

* Smart Folder → Scope
* Policy Engine → Access Control
* Agents → Restricted Execution

### 2.3 "파이프라인이 진실의 원천"

* scan/extract/embed/train/chat/watch
* 모든 에이전트는 이 파이프라인의 산출물을 사용
* drift detection 기반 재임베딩

### 2.4 도메인별 Agent 모델

* Agent는 STT → 요약 → 액션 → 마스킹을 하나의 단위로 운영
* Agent 내부 상태는 artifacts/<agent_name>에 기록

### 2.5 Reliability First

* 캐시 경쟁 방지 (Lock-free atomic writes)
* 재현 가능한 파이프라인
* 정책 위반 시 즉시 fail-fast

## **4. Execution Lifecycle Overview (전체 실행 사이클)**

### 0) Onboarding

* 폴더 선택
* 정책 선택
* 모델 다운로드
* 초기 임베딩 생성

### 1) Smart Folder Scan

* 새 문서 감지
* 변경 문서 감지
* 삭제 문서 처리

### 2) Extract

* 문서 텍스트화
* metadata merge

### 3) Embed + Train

* 문서 분할(chunking)
* 임베딩 생성
* 시맨틱 인덱스 생성
* 토픽 모델(옵션)

### 4) Chat/RAG

* 벡터 검색
* lexical-weight 혼합 점수
* policy-grounded 답변

### 5) Agents

* Meeting Agent: STT → 요약 → 액션 → 저장
* Photo Agent: 분류/중복 제거
* Knowledge Agent: 문서 요약/리포트화

### 6) Drift Monitoring

* 변경된 파일 자동 업데이트
* 캐시 무결성 검사
