# 스마트 폴더 글래스 UI 시안 (초안)

## 1. 목표
- CustomTkinter 기반 스마트 폴더 명령 패널을 투명 카드 느낌으로 표현한다.
- “빠른 명령 입력 + 대표 액션 버튼” 흐름에 집중하고 기본 다크 테마 대비 밝고 가벼운 톤을 만든다.
- 버튼 크기와 간격을 다르게 두어 기능을 직관적으로 구분한다.

## 2. 레이아웃 개요
- **윈도우 크기**: 520×200px (패널 콘텐츠 폭은 약 380px)
- **외곽 여백**: 좌·우·상·하 18px
- **패널(Glass Layer)**  
  - 배경: `#1b2331aa`, 모서리 반경 18px  
  - 테두리: `#3b4a62`, 두께 1px  
  - 상단 강조선: `#6fa8ff55`, 두께 3px, 좌우 120~400px 범위  
  - 우측 하단 글로우: 타원 `#36c2ff22`
- **콘텐츠 정렬**: 패널 중앙에 수직 스택(`제목 → 부제 → 입력창 → 버튼 행`)

## 3. 타이포그래피
| 요소 | 폰트 | 크기 | 색상 | 비고 |
| --- | --- | --- | --- | --- |
| 제목 | `CTkFont(size=18, weight="bold")` | 18px | `#dfe9ff` | 상단 여백 4px |
| 부제 | `CTkFont(size=13)` | 13px | `#8fa1c6` | 제목 아래 여백 0~12px |
| 입력 텍스트 | 시스템 기본 | 13px | `#f0f4ff` | Placeholder는 더 옅게 |

## 4. 입력창
- 크기: 폭 340px, 높이 42px, 중앙 정렬
- 모서리 반경 18px
- 배경: `#141925`, 테두리 `#425b7e`, 두께 2px
- 기본 문구: “무엇이든 부탁하세요” (폴더 컨텍스트에 따라 변경)

## 5. 버튼 행
- 버튼 컨테이너: 투명 Frame, 입력창과 16px 간격
- 버튼 정의:
  | 아이콘 | 역할 | 크기(폭×높이) | 모서리 | 기본색 | Hover |
  | --- | --- | --- | --- | --- | --- |
  | ＋ | 폴더 추가 | 46×46 | 16px | `#202836` | `#2f3b4f` |
  | 🌐 | 전역 검색 | 48×48 | 18px | `#1e2a38` | `#2d3c50` |
  | 🎙 | 음성 명령 | 52×52 | 20px | `#253349` | `#345069` |
  | 📄 | 회의 요약 | 46×46 | 16px | `#202836` | `#2f3b4f` |
  | ⚙️ | 설정 열기 | 42×42 | 14px | `#1c2534` | `#2a3647` |
- 버튼 간격: 좌우 6px, 상하 여백 없음
- 눌림 효과: 텍스트 색 `#9fc7ff`, 그림자 `#0b1018`

## 6. 상태 메시지(선택)
- 패널 우측 상단에 `140×28px` 라벨을 배치
- 배경 `#121722cc`, 텍스트 `#75c2ff`, 모서리 12px
- 2초 후 페이드아웃 처리 (타이머 사용)

## 7. 코드 구성 팁
1. `CTk` 루트의 `fg_color`를 `#0f1115`로 설정해 전체 배경을 어둡게 유지합니다.
2. 루트 내부에 투명 Frame(`fg_color="transparent"`)을 두고 패딩을 적용합니다.
3. `CTkCanvas`로 글래스 효과 영역과 강조선을 그린 뒤 `CTkFrame`을 `place`로 중앙 배치합니다.
4. 버튼은 `command` 인자에 기능별 핸들러(`run_meeting_agent`, `open_settings` 등)를 연결합니다.
5. 스마트 폴더 선택 상태에 따라 입력창 placeholder와 아이콘 강조 상태를 업데이트합니다.

## 8. 향후 개선 메모
- CustomTkinter는 완전한 윈도우 투명도를 지원하지 않으므로 Canvas로 유사 글래스 효과를 냅니다.
- 열기/닫기 애니메이션은 `after`와 `geometry` 조합으로 단계적인 확대 연출을 할 수 있습니다.
- Electron/React 버전으로 확장할 경우 CSS `backdrop-filter: blur()`를 활용하면 더 자연스러운 효과를 구현할 수 있습니다.
