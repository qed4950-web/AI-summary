# 비서 로드맵 요약

- **비전**: 로컬 우선 AI 비서를 하나의 프로그램으로 제공하고, 스마트 폴더 정책으로 검색·학습·요약 범위를 통제합니다.
- **운영 원칙**
  1. 모듈형 플러그인 구조(필요한 에이전트만 온디맨드 로드)
  2. 스마트 폴더 중심 UX(폴더 = 정책)
  3. 로컬 처리 우선, 클라우드 확장은 선택 사항

## 단계별 계획
- **P0 – 코어 & 정책**: 파일 스캐너, 정책 엔진, 스케줄러, 모델 매니저를 통합해 `scan → train → chat` 플로우를 안정화 (완료).
- **P1 – 지식·검색 비서**: 요약/하이라이트, 정책 스코프 전환, 작업 센터 연동 강화 (진행 중).
- **P2 – 회의 비서**: STT·요약 파이프라인 고도화, 액션 아이템/결정 추적 자동화 (진행 중).
- **P3 – 사진 비서**: 태깅, 중복 정리, 베스트샷 추천을 개선하고 GPU/ONNX 경로 정비 (진행 중).
- **P4 – 운영/하이브리드**: 감사·권한 관리, 오프로딩, 모델 자동 선택, 모니터링 대시보드 강화 (예정).

## 단기 우선 과제 (2025년 4분기)
1. **Work Center MVP** – 정책 컨텍스트, 회의/지식 알림을 UI에 연결
2. **Meeting Alert Pipeline** – 회의 요약 결과를 이벤트 버스로 전달하고 테스트
3. **Operations Dashboard** – 감사 로그와 KPI 스크립트를 묶어 관제 지표 제공
4. **Photo Best-shot Policy** – 목적 함수와 캐시 전략 확정, GPU/ONNX 벤치마크 실행
