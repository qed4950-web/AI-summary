# AI-summary 완성도 재평가 (엔진/UI/UX, Round 42) - 2026-02-15

요청한 "가장 중요한 1·2·3 즉시 진행" 기준으로 이번 라운드는  
문서 클릭 열기 실패 체감 이슈와 증분 인덱싱 삭제 정합성, 참조 링크 경로 신뢰도를 우선 보강했다.

## 이번 라운드 Top 1·2·3 즉시 진행

1. 문서 클릭 열기 복구 경로 자동화(UI/UX)
- 파일 원본 경로가 깨진 경우 유사 문서를 자동 탐색해 즉시 열기 시도
- 복구된 경로 캐시를 도입해 동일 문서 재클릭 시 재탐색 없이 복구 경로 재사용
- 사용자에게 "유사 경로 후보/복구 경로" 안내 메시지와 상태를 명확히 표시

2. 증분 인덱싱 삭제 정합성 보강(엔진)
- `run_incremental_index`에서 삭제 파일을 코퍼스/벡터 인덱스에서 즉시 제거하도록 분리 처리
- 삭제 반영 후 `run_step2`는 추가/수정 대상만 처리하도록 스코프 축소
- "삭제만 발생한 배치"에서도 stale 문서가 남지 않도록 계약 테스트로 고정

3. 참조 문서 링크 경로 신뢰도 보강(엔진→UI 연결)
- 백엔드 hit 경로 정규화 시 `DOCS_DIR` 기반 상대경로 복원 추가
- 실제로 해석 불가능한 상대경로는 링크로 내보내지 않도록 fail-closed 처리
- 깨진 링크 클릭률을 줄이고, 유효 링크 중심으로 UX 일관성 강화
